# Phon Dara — Modern Programmer Portfolio

A responsive programmer portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — complete portfolio structure
- `style.css` — responsive dark developer design
- `script.js` — navigation, animations, project filters, form interaction

## Customize before publishing
1. Replace the placeholder GitHub and LinkedIn URLs.
2. Replace `your.email@example.com` with your real email.
3. Add your real GitHub repository URLs to each project.
4. Replace or add project screenshots if you have them.
5. Add your CV PDF and change the "Download CV" link to its file path.
6. Connect the contact form to Formspree, EmailJS, a backend, or your preferred email service if you want real submissions.

## Run locally
Open `index.html` in a browser. For best results, use VS Code with Live Server.

## Deploy
You can publish this static site with GitHub Pages, Netlify, or Vercel.
